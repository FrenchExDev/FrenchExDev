# INJECTABLE-DI — Requirements

## Project Layout

- [ ] **Attributes** project: zero dependencies, `netstandard2.0 + net10.0`. Holds `[Injectable]`, `[InjectableDefaults]`, `[InjectableDecorator]`, `Scope` enum.
- [ ] **SourceGenerator.Lib** project: pure C# with **no Roslyn dependency**. Holds models and emitters.
- [ ] **{Container}.SourceGenerator** projects: one per supported container. Each is `netstandard2.0` and references Roslyn. Each LINKS the SourceGenerator.Lib source files.
- [ ] **Analyzers** project: Roslyn analyzers for build-time safety.
- [ ] **{Container}.Tests** projects: integration tests against a real container instance.

## Attribute Surface

- [ ] `InjectableAttribute` with `Scope`, `As`, `TryAdd`, `Key` properties.
- [ ] `AttributeUsage` allows both `Class` AND `Interface`.
- [ ] `AllowMultiple = true`.
- [ ] `Scope` enum: `Transient`, `Scoped`, `Singleton`. Default is `Transient`.
- [ ] `InjectableDefaultsAttribute` for assembly-level scope defaults.
- [ ] `InjectableDecoratorAttribute` for cross-cutting decorators.

## Source Generator Behavior

- [ ] Uses `ForAttributeWithMetadataName` for incremental performance.
- [ ] Class pipeline → `InjectableServiceModel` instances.
- [ ] Interface pipeline → `InterfaceContractModel` instances; auto-discovers implementations.
- [ ] Decorator pipeline → `InjectableDecoratorModel` instances.
- [ ] Reads `[InjectableDefaults]` for assembly default scope.
- [ ] Skips abstract classes silently (analyzer reports the warning).
- [ ] Detects open generic classes and emits `typeof(...)` registrations.
- [ ] Emits exactly **one extension method per assembly** in `InjectableExtensions.g.cs`.
- [ ] Method name derived from assembly name via PascalCase sanitization.

## Interface Resolution

- [ ] `As` specified → register only as that type.
- [ ] No `As`, has interfaces → register for each directly implemented interface.
- [ ] No `As`, no interfaces → register as self.
- [ ] Interface scope contract (`[Injectable]` on interface) → implementations inherit scope.

## Registration Modes

- [ ] Standard `Add{Lifetime}<I, T>()`.
- [ ] `TryAdd{Lifetime}` when `TryAdd = true`.
- [ ] `AddKeyed{Lifetime}<I, T>(key)` for `Key`-set entries (gated `#if NET8_0_OR_GREATER`).
- [ ] Open generic `services.AddXxx(typeof(IFoo<>), typeof(Foo<>))`.
- [ ] Decorator pattern via container-specific mechanism.

## Analyzer Set

- [ ] **INJECT001** (Warning): captive dependency — Singleton depends on Scoped/Transient.
- [ ] **INJECT002** (Warning): `[Injectable]` on abstract class.
- [ ] **INJECT003** (Info): class implements service interface but lacks `[Injectable]`.
- [ ] **INJECT004** (Error): implementation scope conflicts with interface scope contract.

## Generated Code Quality

- [ ] Generated code is plain `services.AddXxx<>(...)` calls.
- [ ] Uses fully-qualified type names (`global::Namespace.Type`).
- [ ] Wrapped in `// <auto-generated />` and `#nullable enable`.
- [ ] AOT-compatible — no reflection, no expression trees.

## What MUST NOT Be Done

- [ ] No reflection-based scanning at runtime.
- [ ] No assembly loading at runtime.
- [ ] No DI container auto-detection — generators are container-specific by design.
- [ ] Attributes project MUST NOT depend on Microsoft.Extensions.DependencyInjection or DryIoc.
- [ ] SourceGenerator.Lib MUST NOT depend on Roslyn — that's the point of the split.
- [ ] Generated code MUST NOT use reflection in the generated extension method.

## Multi-Targeting

- [ ] Attributes: `netstandard2.0 + net10.0`.
- [ ] SourceGenerator.Lib: `netstandard2.0`.
- [ ] {Container}.SourceGenerator: `netstandard2.0` (Roslyn requirement).
- [ ] Analyzers: `netstandard2.0` (Roslyn requirement).
