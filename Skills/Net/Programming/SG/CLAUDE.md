## Notes for Claude
- `.Lib` has ZERO Roslyn dependency — plain data models and StringBuilder emission only
- `.SourceGenerator` and `.Lib` must target `netstandard2.0` — no Span<T>, no `init`, no IAsyncEnumerable
- `.SourceGenerator` must be packaged as analyzer: `<IsRoslynComponent>true</IsRoslynComponent>`
- Incremental generators cache aggressively — model must implement proper `Equals`/`GetHashCode`
- `BuilderEmitter` is shared infrastructure for 4+ generators — never fork it, use extension points
- Generated files include `// <auto-generated/>` header and `.g.cs` suffix
- Use `ForAttributeWithMetadataName` for attribute-triggered generation
