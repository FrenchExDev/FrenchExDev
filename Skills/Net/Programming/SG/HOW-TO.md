# SG (Source Generators) — How-To

## Creating a New Source Generator

### Step 1: Create the 4-project layout

```
{Name}/
  src/
    FrenchExDev.Net.{Name}/                      (netstandard2.0;net10.0)
    FrenchExDev.Net.{Name}.Attributes/            (netstandard2.0;net10.0)
    FrenchExDev.Net.{Name}.SourceGenerator/       (netstandard2.0)
    FrenchExDev.Net.{Name}.SourceGenerator.Lib/   (netstandard2.0)
  test/
    FrenchExDev.Net.{Name}.Tests/                 (net10.0)
```

### Step 2: Define the trigger attribute

In `.Attributes`:
```csharp
[AttributeUsage(AttributeTargets.Class, AllowMultiple = false)]
public sealed class MyAttribute : Attribute
{
    public string Name { get; }
    public MyAttribute(string name) => Name = name;
}
```

### Step 3: Create the emission model

In `.SourceGenerator.Lib` (no Roslyn references):
```csharp
public sealed class MyEmitModel
{
    public string Namespace { get; init; } = "";
    public string ClassName { get; init; } = "";
    public IReadOnlyList<MyPropertyModel> Properties { get; init; } = [];
}
```

### Step 4: Create the emitter

In `.SourceGenerator.Lib`:
```csharp
public static class MyEmitter
{
    public static string Emit(MyEmitModel model)
    {
        var sb = new StringBuilder();
        sb.AppendLine("// <auto-generated/>");
        sb.AppendLine($"namespace {model.Namespace};");
        sb.AppendLine($"public partial class {model.ClassName}");
        sb.AppendLine("{");
        // ... generate members
        sb.AppendLine("}");
        return sb.ToString();
    }
}
```

### Step 5: Create the generator

In `.SourceGenerator`:
```csharp
[Generator]
public sealed class MyGenerator : IIncrementalGenerator
{
    public void Initialize(IncrementalGeneratorInitializationContext context)
    {
        var models = context.SyntaxProvider
            .ForAttributeWithMetadataName(
                "FrenchExDev.Net.{Name}.Attributes.MyAttribute",
                predicate: static (node, _) => node is ClassDeclarationSyntax,
                transform: static (ctx, ct) => GetModel(ctx, ct))
            .Where(static m => m is not null);

        context.RegisterSourceOutput(models, static (ctx, model) =>
        {
            var source = MyEmitter.Emit(model!);
            ctx.AddSource($"{model!.ClassName}.g.cs",
                SourceText.From(source, Encoding.UTF8));
        });
    }

    private static MyEmitModel? GetModel(
        GeneratorAttributeSyntaxContext ctx, CancellationToken ct)
    {
        // Extract ISymbol data -> MyEmitModel (plain strings, no Roslyn types)
    }
}
```

## Reusing BuilderEmitter

When your domain SG needs to generate builders, construct a `BuilderEmitModel` and call `BuilderEmitter.Emit()`:

```csharp
// In your domain SG's helper (e.g., DockerCompose/BuilderHelper.cs)
var model = new BuilderEmitModel
{
    Namespace = "My.Namespace",
    TargetClassName = "MyClass",
    BuilderClassName = "MyClassBuilder",
    Instantiation = "init",
    Preamble = "// Custom domain-specific code here",
    Properties = properties.Select(p => new BuilderPropertyModel
    {
        Name = p.Name,
        TypeName = p.Type,
        WithMethodAttributes = new[] { "[MyCustomAttribute]" },
    }).ToList(),
};

var source = BuilderEmitter.Emit(model);
```

Reference: `DockerCompose/src/.../BuilderHelper.cs`

## Testing a Source Generator

### Test the emitter (`.Lib`) directly:
```csharp
[Fact]
public void Emits_correct_class()
{
    var model = new MyEmitModel { Namespace = "Test", ClassName = "Foo" };
    var source = MyEmitter.Emit(model);
    source.ShouldContain("public partial class Foo");
}
```

### Test the full generator with in-memory compilation:
```csharp
[Fact]
public void Generator_produces_valid_code()
{
    var source = @"
        using My.Namespace;
        [My] public partial class Foo { public string Name { get; set; } }
    ";
    var compilation = CreateCompilation(source);
    var generator = new MyGenerator();
    var driver = CSharpGeneratorDriver.Create(generator);
    driver = (CSharpGeneratorDriver)driver.RunGenerators(compilation);
    var result = driver.GetRunResult();
    result.Diagnostics.ShouldBeEmpty();
    result.GeneratedTrees.Length.ShouldBeGreaterThan(0);
}
```

## Common Pitfalls

- **netstandard2.0 constraints** — no `Span<T>`, no `IAsyncEnumerable`, no `init` accessors in `.SourceGenerator` and `.Lib` projects. Use `{ get; set; }` in models.
- **Analyzer packaging** — `.SourceGenerator` must be packaged as an analyzer. Ensure the `.csproj` has `<IsRoslynComponent>true</IsRoslynComponent>`.
- **`ForAttributeWithMetadataName`** — use fully qualified attribute name including namespace.
- **Caching** — incremental generators cache aggressively. If output doesn't change, check that your model implements proper `Equals`/`GetHashCode`.

## Debugging Generated Code

- **Inspect `obj/Generated/`** — the generated `.g.cs` files are written here during build.
- **Add `EmitCompilerGeneratedFiles`** to `.csproj` if files aren't appearing:
  ```xml
  <EmitCompilerGeneratedFiles>true</EmitCompilerGeneratedFiles>
  ```
- **Log during development** — use `context.ReportDiagnostic()` with `DiagnosticSeverity.Warning` to emit debug messages visible in build output.
