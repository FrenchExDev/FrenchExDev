Manage GitLab Agents for Kubernetes and their clusters.

USAGE
  glab cluster <command> [flags]

CORE COMMANDS
  agent:      Manage GitLab Agents for Kubernetes.
  graph:      Queries the Kubernetes object graph, using the GitLab Agent for Kubernetes. (EXPERIMENTAL)

FLAGS
  -R, --repo OWNER/REPO   Select another repository. Can use either OWNER/REPO or `GROUP/NAMESPACE/REPO` format. Also accepts full URL or Git URL.

INHERITED FLAGS
  -h, --help   Show help for this command.

LEARN MORE
  Use 'glab <command> <subcommand> --help' for more information about a command.
