Work with GitLab CI/CD schedules.

USAGE
  glab schedule <command> [flags]

ALIASES
  sched, skd

CORE COMMANDS
  create:     Schedule a new pipeline.
  delete:     Delete the schedule with the specified ID.
  list:       Get the list of schedules.
  run:        Run the specified scheduled pipeline.
  update:     Update a pipeline schedule.

FLAGS
  -R, --repo OWNER/REPO   Select another repository. Can use either OWNER/REPO or `GROUP/NAMESPACE/REPO` format. Also accepts full URL or Git URL.

INHERITED FLAGS
  --help   Show help for this command.

LEARN MORE
  Use 'glab <command> <subcommand> --help' for more information about a command.
