Manage labels on remote.

USAGE
  glab label <command> [flags]

CORE COMMANDS
  create:     Create labels for a repository or project.
  delete:     Delete labels for a repository or project.
  list:       List labels in the repository.

FLAGS
  -R, --repo OWNER/REPO   Select another repository. Can use either OWNER/REPO or `GROUP/NAMESPACE/REPO` format. Also accepts full URL or Git URL.

INHERITED FLAGS
  -h, --help   Show help for this command.

LEARN MORE
  Use 'glab <command> <subcommand> --help' for more information about a command.
