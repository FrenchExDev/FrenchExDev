Work with GitLab CI/CD pipelines and jobs.

USAGE
  glab ci <command> [flags]

ALIASES
  pipe, pipeline

CORE COMMANDS
  artifact:   Download all artifacts from the last pipeline.
  cancel:     Cancel a running pipeline or job.
  config:     Work with GitLab CI/CD configuration.
  delete:     Delete CI/CD pipelines.
  get:        Get JSON of a running CI/CD pipeline on the current or other specified branch.
  lint:       Checks if your `.gitlab-ci.yml` file is valid.
  list:       Get the list of CI/CD pipelines.
  retry:      Retry a CI/CD job.
  run:        Create or run a new CI/CD pipeline.
  run-trig:   Run a CI/CD pipeline trigger.
  status:     View a running CI/CD pipeline on current or other branch specified.
  trace:      Trace a CI/CD job log in real time.
  trigger:    Trigger a manual CI/CD job.
  view:       View, run, trace, log, and cancel CI/CD job's current pipeline.

FLAGS
  -R, --repo OWNER/REPO   Select another repository. Can use either OWNER/REPO or `GROUP/NAMESPACE/REPO` format. Also accepts full URL or Git URL.

INHERITED FLAGS
  -h, --help   Show help for this command.

LEARN MORE
  Use 'glab <command> <subcommand> --help' for more information about a command.
