
  Manage your to-do list.                                                                                               
         
  USAGE  
         
    glab todo <command> [command] [--flags]  
            
  EXAMPLES  
            
    glab todo list                           
    glab todo done 123                       
    glab todo done --all                     
            
  COMMANDS  
            
    done [<id>] [--flags]  Mark a to-do item as done.
    list [--flags]         List your to-do items.
         
  FLAGS  
         
    -h --help              Show help for this command.
