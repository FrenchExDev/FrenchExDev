Work with GitLab issue boards in the given project.

USAGE
  glab issue board [command] [flags]

CORE COMMANDS
  create:     Create a project issue board.
  view:       View project issue board.

FLAGS
  -R, --repo string   Select another repository using the OWNER/REPO format or the project ID. Supports group namespaces.

INHERITED FLAGS
  -h, --help   Show help for this command.

LEARN MORE
  Use 'glab <command> <subcommand> --help' for more information about a command.
