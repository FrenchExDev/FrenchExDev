
  Manages GitLab CI/CD runners for projects, groups, or the entire instance.                                            
                                                                                                                        
         
  USAGE  
         
    glab runner <command> [command] [--flags]  
            
  COMMANDS  
            
    delete <runner-id> [--flags]  Delete a GitLab CI/CD runner.
    list [--flags]                List GitLab CI/CD runners.
    update <runner-id> [--flags]  Update a GitLab CI/CD runner.
         
  FLAGS  
         
    -h --help                     Show help for this command.
    -R --repo                     Select another repository. Can use either `OWNER/REPO` or `GROUP/NAMESPACE/REPO` format. Also accepts full URL or Git URL.
