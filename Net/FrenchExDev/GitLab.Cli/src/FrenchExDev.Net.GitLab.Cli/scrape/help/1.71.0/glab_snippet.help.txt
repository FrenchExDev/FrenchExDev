Create, view and manage snippets.

USAGE
  glab snippet <command> [flags]

CORE COMMANDS
  create:     Create a new snippet.

FLAGS
  -R, --repo OWNER/REPO   Select another repository. Can use either OWNER/REPO or `GROUP/NAMESPACE/REPO` format. Also accepts full URL or Git URL.

INHERITED FLAGS
  -h, --help   Show help for this command.

ARGUMENTS
  A snippet can be supplied as argument in the following format:
  - by number, e.g. "123"

EXAMPLES
  $ glab snippet create --title "Title of the snippet" --filename "main.go"

LEARN MORE
  Use 'glab <command> <subcommand> --help' for more information about a command.
