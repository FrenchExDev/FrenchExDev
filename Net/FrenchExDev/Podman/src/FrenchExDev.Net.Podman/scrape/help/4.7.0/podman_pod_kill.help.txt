Send the specified signal or SIGKILL to containers in pod

Description:
  Signals are sent to the main process of each container inside the specified pod.

  The default signal is SIGKILL, or any signal specified with option --signal.

Usage:
  podman pod kill [options] POD [POD...]

Examples:
  podman pod kill podID
  podman pod kill --signal TERM mywebserver
  podman pod kill --latest

Options:
  -a, --all             Kill all containers in all pods
  -s, --signal string   Signal to send to the containers in the pod (default "KILL")
