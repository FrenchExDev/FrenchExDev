Create a new secret

Description:
  Create a secret. Input can be a path to a file or "-" (read from stdin). Default driver is file (unencrypted).

Usage:
  podman secret create [options] NAME FILE|-

Examples:
  podman secret create mysecret /path/to/secret
		printf "secretdata" | podman secret create mysecret -

Options:
  -d, --driver string                Specify secret driver (default "file")
      --driver-opts stringToString   Specify driver specific options (default [])
      --env                          Read secret data from environment variable
  -l, --label stringArray            Specify labels on the secret
