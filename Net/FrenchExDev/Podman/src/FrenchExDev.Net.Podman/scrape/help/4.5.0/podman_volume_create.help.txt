Create a new volume

Description:
  If using the default driver, "local", the volume will be created on the host in the volumes directory under container storage.

Usage:
  podman volume create [options] [NAME]

Examples:
  podman volume create myvol
  podman volume create
  podman volume create --label foo=bar myvol

Options:
  -d, --driver string     Specify volume driver name (default "local")
      --ignore            Don't fail if volume already exists
  -l, --label strings     Set metadata for a volume (default [])
  -o, --opt stringArray   Set driver specific options (default [])
