List secrets

Description:
  

Usage:
  podman secret ls [options]

Aliases:
  ls, list

Examples:
  podman secret ls

Options:
  -f, --filter strings   Filter secret output
      --format string    Format volume output using Go template (default "{{.ID}}\t{{.Name}}\t{{.Driver}}\t{{.CreatedAt}}\t{{.UpdatedAt}}\t\n")
      --noheading        Do not print headers
