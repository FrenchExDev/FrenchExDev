Remove Quadlets

Description:
  Remove one or more installed Quadlets from the current user

Usage:
  podman quadlet rm [options] QUADLET [QUADLET...]

Examples:
  podman quadlet rm test.container
podman quadlet rm --force mysql.container
podman quadlet rm --all --reload-systemd=false

Options:
  -a, --all              Remove all Quadlets for the current user
  -f, --force            Remove running quadlets
  -i, --ignore           Do not error for Quadlets that do not exist
      --reload-systemd   Reload systemd after removal (default true)
