Remove unused data

Description:
  
	podman system prune

        Remove unused data


Usage:
  podman system prune [options]

Examples:
  podman system prune

Options:
  -a, --all                  Remove all unused data
      --filter stringArray   Provide filter values (e.g. 'label=<key>=<value>')
  -f, --force                Do not prompt for confirmation.  The default is false
      --volumes              Prune volumes
