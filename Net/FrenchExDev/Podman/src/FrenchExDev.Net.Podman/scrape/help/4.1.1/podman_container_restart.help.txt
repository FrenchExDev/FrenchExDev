Restart one or more containers

Description:
  Restarts one or more running containers. The container ID or name can be used.

  A timeout before forcibly stopping can be set, but defaults to 10 seconds.

Usage:
  podman container restart [options] CONTAINER [CONTAINER...]

Examples:
  podman container restart ctrID
  podman container restart --latest
  podman container restart ctrID1 ctrID2

Options:
  -a, --all         Restart all non-running containers
      --running     Restart only running containers when --all is used
  -t, --time uint   Seconds to wait for stop before killing the container (default 10)
