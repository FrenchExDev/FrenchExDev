usage: git commit-graph verify [--object-dir <objdir>] [--shallow] [--[no-]progress]
   or: git commit-graph write [--object-dir <objdir>] [--append] [--split[=<strategy>]] [--reachable|--stdin-packs|--stdin-commits] [--changed-paths] [--[no-]max-new-filters <n>] [--[no-]progress] <split options>

    --object-dir <dir>    the object directory to store the graph
