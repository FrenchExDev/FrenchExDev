usage: git backfill [--min-batch-size=<n>] [--[no-]sparse] [--[no-]include-edges] [<revision-range>]

    --min-batch-size <n>  Minimum number of objects to request at a time
    --[no-]sparse         Restrict the missing objects to the current sparse-checkout
    --[no-]include-edges  Include blobs from boundary commits in the backfill
