## Notes for Claude
- This is **not** a BinaryWrapper consumer. It is a domain-specific version-discovery library that queries `dl-cdn.alpinelinux.org` directly.
- `AlpineVersion` parses semver-ish strings plus the special tokens `edge` and `_rc1` / `_rc2` release-candidate suffixes. Do not assume strict semver.
- Searching is parallelised at up to 10 concurrent HTTP requests — the constant lives in the searcher.
- SHA-256 and SHA-512 checksums are fetched alongside each release record. The checksum URLs are derived from the artifact path; do not hard-code.
- Pure .NET 10.0 with zero NuGet dependencies. Do not add any.
- Builder-style filter API (`AlpineVersionSearchingFiltersBuilder`) is hand-written, not generated by the `[Builder]` source generator.
