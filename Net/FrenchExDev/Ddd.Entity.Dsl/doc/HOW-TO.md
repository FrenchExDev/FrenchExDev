## 1. Adding the Bridge SG

Reference the bridge SG as an analyzer in your domain project:

```xml
<ItemGroup>
  <ProjectReference
    Include="path/to/FrenchExDev.Net.Ddd.Entity.Dsl.SourceGenerator.csproj"
    OutputItemType="Analyzer"
    ReferenceOutputAssembly="false" />
</ItemGroup>
```

Also reference the Ddd attributes and Entity.Dsl SG in the same project so both stages run.

## 2. Using DDD Attributes

Write your domain model with DDD attributes. Classes must be `partial`:

```csharp
using FrenchExDev.Net.Ddd.Attributes;

[AggregateRoot("Order")]
public partial class Order
{
    [EntityId]
    public Guid Id { get; set; }

    public string CustomerName { get; set; } = "";
    public decimal Total { get; set; }

    [Composition]
    public List<OrderLine> Lines { get; set; } = [];

    [Aggregation]
    public Customer Customer { get; set; } = null!;

    [Association]
    public User CreatedBy { get; set; } = null!;
}

[Entity("OrderLine")]
public partial class OrderLine
{
    [EntityId]
    public Guid Id { get; set; }

    public string ProductName { get; set; } = "";
    public int Quantity { get; set; }
}
```

## 3. What Gets Generated

For each `[AggregateRoot]` or `[Entity]` class, the bridge SG emits a `.DddBridge.g.cs` file with all Entity.Dsl attributes derived from DDD attributes.

**`Order.DddBridge.g.cs`:**
```csharp
// <auto-generated/>
// Generated by Ddd.Entity.Dsl bridge -- maps DDD attributes to Entity.Dsl attributes.
#nullable enable

namespace MyApp.Domain;

[global::FrenchExDev.Net.Entity.Dsl.Attributes.MappedEntity]
[global::FrenchExDev.Net.Entity.Dsl.Attributes.PrimaryKey("Id")]
[global::FrenchExDev.Net.Entity.Dsl.Attributes.NavigationProperty("Lines", OnDelete = global::FrenchExDev.Net.Entity.Dsl.Attributes.DeleteBehavior.Cascade)]
[global::FrenchExDev.Net.Entity.Dsl.Attributes.NavigationProperty("Customer", OnDelete = global::FrenchExDev.Net.Entity.Dsl.Attributes.DeleteBehavior.Restrict)]
[global::FrenchExDev.Net.Entity.Dsl.Attributes.NavigationProperty("CreatedBy", OnDelete = global::FrenchExDev.Net.Entity.Dsl.Attributes.DeleteBehavior.NoAction)]
public partial class Order
{
}
```

**`OrderLine.DddBridge.g.cs`:**
```csharp
// <auto-generated/>
// Generated by Ddd.Entity.Dsl bridge -- maps DDD attributes to Entity.Dsl attributes.
#nullable enable

namespace MyApp.Domain;

[global::FrenchExDev.Net.Entity.Dsl.Attributes.MappedEntity]
[global::FrenchExDev.Net.Entity.Dsl.Attributes.PrimaryKey("Id")]
public partial class OrderLine
{
}
```

The Entity.Dsl SG then reads `[MappedEntity]`, `[PrimaryKey]`, and `[NavigationProperty]` to generate:
- `OrderConfigurationBase` with `HasKey`, `OnDelete` fluent API
- `OrderConfiguration` partial stub (developer extends via second partial)
- `OrderConfigurationRegistration` implementing `IEntityTypeConfiguration<T>`
- DbContext with `DbSet<Order>` and `DbSet<OrderLine>`
- Repository interfaces and implementations
- UnitOfWork interface and implementation

## 5. Attribute Mapping Reference

The bridge generator scans each `[AggregateRoot]` / `[Entity]` class and its public properties for DDD attributes, then emits the corresponding Entity.Dsl attributes at class level.

| DDD Attribute (on property) | Entity.Dsl Attribute (on class) | Effect |
|----------------------------|--------------------------------|--------|
| `[EntityId]` | `[PrimaryKey("PropName")]` | Marks property as PK (composite key if multiple) |
| `[Composition]` | `[NavigationProperty("PropName", OnDelete = Cascade)]` | Owned child -- cascading delete |
| `[Aggregation]` | `[NavigationProperty("PropName", OnDelete = Restrict)]` | Shared reference -- restrict delete |
| `[Association]` | `[NavigationProperty("PropName", OnDelete = NoAction)]` | Loose link -- no cascade |

**Why class-level?** C# partial classes cannot add attributes to properties declared in another partial. The bridge emits a separate partial class, so it can only contribute class-level attributes and new members. The Entity.Dsl SG reads these class-level attributes to configure EF Core.

## 6. Composite Primary Keys

If an entity has multiple `[EntityId]` properties, the bridge emits a composite key:

```csharp
[Entity("TenantUser")]
public partial class TenantUser
{
    [EntityId]
    public Guid TenantId { get; set; }

    [EntityId]
    public Guid UserId { get; set; }
}
```

Generated:
```csharp
[global::FrenchExDev.Net.Entity.Dsl.Attributes.MappedEntity]
[global::FrenchExDev.Net.Entity.Dsl.Attributes.PrimaryKey("TenantId", "UserId")]
public partial class TenantUser
{
}
```

The Entity.Dsl SG translates this to `builder.HasKey(e => new { e.TenantId, e.UserId })`.

## 7. Relationship Types

### Composition (strong ownership)

The child cannot exist without the parent. Deleting the parent cascades to children.

```csharp
[Composition]
public List<OrderLine> Lines { get; set; } = [];
```
-> `[NavigationProperty("Lines", OnDelete = DeleteBehavior.Cascade)]`

### Aggregation (shared reference)

The child has its own lifecycle but is referenced by the parent. Deletion is restricted while references exist.

```csharp
[Aggregation]
public Customer Customer { get; set; } = null!;
```
-> `[NavigationProperty("Customer", OnDelete = DeleteBehavior.Restrict)]`

### Association (loose link)

Independent entities with no ownership. No cascading behavior.

```csharp
[Association]
public User CreatedBy { get; set; } = null!;
```
-> `[NavigationProperty("CreatedBy", OnDelete = DeleteBehavior.NoAction)]`

## 8. Manual MappedEntity (Without Bridge)

If you don't use DDD attributes, you can add Entity.Dsl attributes directly:

```csharp
using FrenchExDev.Net.Entity.Dsl.Attributes;

[MappedEntity]
[PrimaryKey("Id")]
[NavigationProperty("Items", OnDelete = DeleteBehavior.Cascade)]
public partial class Product
{
    public Guid Id { get; set; }
    public string Name { get; set; } = "";
    public List<ProductItem> Items { get; set; } = [];
}
```

The bridge SG is only needed when you want DDD attributes to automatically trigger Entity.Dsl generation.

## 9. Running Tests

```bash
dotnet test Ddd.Entity.Dsl/FrenchExDev.Net.Ddd.Entity.Dsl.slnx
```

Test suite: 10 xUnit tests verifying:
- `[MappedEntity]` attribute is emitted on partial class
- Auto-generated header and bridge comment are present
- Namespace is correctly applied
- `[EntityId]` -> `[PrimaryKey]` mapping (single and composite)
- `[Composition]` -> `[NavigationProperty(OnDelete = Cascade)]`
- `[Aggregation]` -> `[NavigationProperty(OnDelete = Restrict)]`
- `[Association]` -> `[NavigationProperty(OnDelete = NoAction)]`
- Full aggregate root with all relationship types combined
- Empty model emits only `[MappedEntity]` (no spurious attributes)
