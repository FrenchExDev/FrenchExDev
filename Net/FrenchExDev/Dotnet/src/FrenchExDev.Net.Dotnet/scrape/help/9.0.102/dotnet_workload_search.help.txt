Description:
  Search for available workloads.

Usage:
  dotnet workload search [<SEARCH_STRING>] [command] [options]

Arguments:
  <SEARCH_STRING>  The text to search for in the IDs and descriptions of available workloads.

Options:
  -?, -h, --help  Show command line help.

Commands:
  version <WORKLOAD_VERSION>  Output a list of the latest released workload versions. Takes the --take option to specify how many to provide and --format to alter the format.
