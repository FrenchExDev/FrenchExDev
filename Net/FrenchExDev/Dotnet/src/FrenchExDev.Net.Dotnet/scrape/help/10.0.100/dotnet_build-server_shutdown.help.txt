Description:
  Shuts down build servers that are started from dotnet. By default, all servers are shut down.

Usage:
  dotnet build-server shutdown [options]

Options:
  --msbuild       Shut down the MSBuild build server. [default: False]
  --vbcscompiler  Shut down the VB/C# compiler build server. [default: False]
  --razor         Shut down the Razor build server. [default: False]
  -?, -h, --help  Show command line help.
