Description:
  Output a list of the latest released workload versions. Takes the --take option to specify how many to provide and --format to alter the format.

Usage:
  dotnet workload search [<SEARCH_STRING>] version [<WORKLOAD_VERSION>] [options]

Arguments:
  <SEARCH_STRING>     The text to search for in the IDs and descriptions of available workloads.
  <WORKLOAD_VERSION>  Output workload manifest versions associated with the provided workload version.

Options:
  --format <format>  Changes the format of outputted workload versions. Can take 'json' or 'list'
  --take <take>      [default: 5]
  -?, -h, --help     Show command line help.
